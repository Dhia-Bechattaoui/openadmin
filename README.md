# OpenAdmin

The privacy-first "Life Ops" Dashboard.

This project is built using Tauri, Rust, and React. It runs entirely locally to keep your sensitive personal documents, warranties, and subscription details out of the cloud.

## Features
- Receipt OCR and Warranty Tracking
- Document Expiration Reminders
- Subscription Free-Trial Tracking

## Stack
- **Framework:** Tauri v2
- **Backend:** Rust + embedded SQLite
- **Frontend:** Vite + React + TypeScript
- **OCR:** Local Tesseract.js
